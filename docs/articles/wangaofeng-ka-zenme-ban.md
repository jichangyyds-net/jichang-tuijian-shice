「白天好好的，一到晚上八点就卡成 PPT」——这是机场用户最高频的抱怨，没有之一。

在换机场之前，先花十分钟搞清楚问题出在哪。有些情况换一家没用，有些情况换个节点就好了。

## 三类成因

### 一、机场超售（最常见）

一条 1Gbps 的带宽，卖给一千个人用。

白天大家在上班上学，同时在线的可能只有一百人，人均带宽充足。晚上八点所有人回家开始刷视频，同时在线五百人，人均带宽直接掉到五分之一。

**这是低价走量档的结构性特征，不是运营方偷懒。** ¥10/月的定价本身就无法支撑一人一份的带宽预算，超售是这个价位能存在的前提。

### 二、公网国际出口拥堵

即便机场不超售，中转和直连线路的跨境那一跳要走公网国际出口，而这条路在晚高峰本身就堵——全国的跨境流量都挤在那里。

**这是为什么专线要贵三倍**：IPLC / IEPL 走运营商内网通道，不参与公网出口的抢占。详细的架构差异见 [IPLC 与 IEPL 详解](iplc-iepl-zhongzhuan-zhilian.md)。

### 三、你自己的问题（别忽略）

在骂机场之前先排除这几项：

- **流量用超被限速。** 很多套餐超过额度后会降速而不是断网，表现和晚高峰卡顿很像。先看用户中心的剩余流量。
- **用了高倍率节点。** `2x` 节点扣流量是双倍的，你可能比自己以为的用得快得多。
- **本地网络问题。** 关掉代理测一下国内网站的速度，如果本身就慢，那是你的宽带或 Wi-Fi 的事。
- **客户端开了负载均衡。** 频繁切换节点会导致连接不稳定，晚上尤其明显。固定单节点试试。

## 一套可复现的测试方法

模糊的「感觉很卡」没法用来做决策，需要数字。

**测试步骤：**

1. 选一个你日常最常用的节点，**固定它**，整个测试期间不要换。
2. **白天基准**：工作日 14:00 左右，用 Speedtest 测一次下载速度，记下来。
3. **晚高峰**：连续三个工作日的 21:00 左右，各测一次，记录下载速度**和丢包率**。
4. 取三次晚高峰结果里**最低**的那个——这才是你的真实体验下限，不要取平均值。

**怎么读结果：**

| 晚高峰 / 白天 | 判断 |
| --- | --- |
| 掉到 70% 以上 | 正常波动，这条线路没问题 |
| 掉到 50%–70% | 有超售但可接受，看你能不能忍 |
| 掉到 50% 以下 | 超售严重，或者根本不是它宣传的专线 |

**另外，丢包比延迟更重要。** 延迟 60ms 但丢包 5% 的线路，实际体验远差于延迟 120ms 零丢包的。视频缓冲、游戏瞬移，多数是丢包造成的，不是延迟。

## 能自己解决的情况

**换个节点试试。** 同一个机场不同节点的负载差别可能很大。热门的香港节点晚上挤爆，冷门的日本或新加坡节点可能还很空。

**避开标着「推荐」的节点。** 大家都往那儿挤。

**关掉客户端的自动测速切换。** 晚高峰所有节点都慢，自动切换会导致连接反复中断，体验更差。

**降低画质。** Netflix 4K 需要持续 25Mbps 以上，降到 1080P 对带宽的要求会低很多。

## 该换机场的信号

如果出现下面任意一种，别折腾了，问题不在你这边：

- **所有节点、所有地区在晚高峰都不可用**，持续一周以上
- **晚高峰速度掉到白天的 30% 以下**，这已经不是「有点挤」的程度
- **工单反馈后没有任何改善或说明**，说明运营方不打算扩容

## 但换之前先想清楚一件事

**如果你原本用的是低价走量档，换另一家同价位的，大概率还是一样的结果。**

这是模式决定的，不是运气问题。¥10 的价格买不到不超售的带宽——换十家还是这个价位，结果不会变。

所以正确的做法是**跨档位换**：

- 从低价档换到 [¥14–24 的主流性价比档](https://www.jichangyyds.com/topics/stable/)，通常能拿到质量明显更好的 BGP 中转
- 如果你的主要使用时间就是晚上，而且对卡顿零容忍，直接上 [¥25 以上的专线档](https://www.jichangyyds.com/topics/dedicated-line/)

具体清单见[晚高峰稳定机场推荐](https://www.jichangyyds.com/topics/peak-hour/)。

换之前照例提醒两句：先对照[已跑路名单](https://www.jichangyyds.com/scam/)确认目标不在里面，然后**买月付**，用上面那套三天测试法验证过再考虑续长期套餐。别拿年付去赌一个还没验证过的机场。

其他故障（节点全红、订阅失效、Netflix 报错、ChatGPT 不可用）的排查方法，见[机场报错排查页](https://www.jichangyyds.com/troubleshoot/)。
