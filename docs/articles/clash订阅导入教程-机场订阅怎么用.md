Clash 系客户端是中文用户占比最高的一类。这篇讲清楚从拿到订阅链接到能正常上网的完整流程。

## 先搞清楚你在用哪个 Clash

「Clash」现在指的是一整个家族，常见的有：

- **Clash Verge Rev**：桌面端（Windows / macOS / Linux）目前最主流的图形客户端，内置 Mihomo 内核
- **Clash Meta / Mihomo**：内核名称，支持 Hysteria2、TUIC、VLESS Reality 等新协议
- **Stash**：iOS / macOS 上的商业客户端，配置语法兼容

原版 Clash 已停止维护，**新协议基本都需要 Meta（Mihomo）内核**。如果你的机场主推 Hysteria2 这类新协议，务必确认客户端版本跟得上。

## 导入步骤（Clash Verge Rev）

1. **拿订阅链接。** 登录机场用户中心，找到「订阅」或「一键订阅」，复制 **Clash 格式**的链接。注意不是通用订阅。
2. **打开 Verge → 订阅（Profiles）。**
3. **粘贴链接 → 点导入。** 几秒后会出现一个配置卡片。
4. **点这个卡片启用它。**
5. **到「代理」页选节点。** 上面有策略组（自动选择 / 手动 / 故障转移等），下面是节点列表。
6. **回到「设置」开启系统代理。** 这一步不开的话，浏览器的流量根本不会走 Clash。

正常情况下这时候就能用了。

## 为什么要用 Clash 专属订阅

机场通常提供好几种订阅格式，很多人随手复制第一个就用了，这会踩坑。

**通用订阅（Base64）里只有节点信息，没有策略组和规则。** 导进 Clash 之后，客户端要么用默认规则，要么靠第三方订阅转换服务临时生成——前者分流不准，后者等于**把你的全部节点信息交给一个陌生的中间人**。

原生 Clash 订阅里，机场已经把策略组、地区分组、流媒体分流规则都配好了。导入即用，而且机场更新规则时你自动同步。

## 读懂节点名

规范的机场会在节点名里塞进关键信息，比如：

```
香港 01 | IEPL | 1x
日本 东京 | 中转 | 2x
```

- **地区**：决定你能解锁哪个区的内容
- **线路类型**：IEPL / IPLC 是专线，中转和直连走公网，差别见 [IPLC 与 IEPL 详解](iplc-iepl-zhongzhuan-zhilian.md)
- **倍率**：`2x` 表示用 1GB 实际扣 2GB 流量。高倍率节点通常是成本更高的优质线路

**节点名混乱、什么都不标的机场要留个心眼**——你根本不知道自己在用哪条线、扣多少流量。

## 规则模式怎么选

Verge 顶部有三种模式：

- **规则（Rule）**：按订阅里的规则分流，国内网站直连、国外走代理。**日常就用这个**，省流量也省得国内网站变慢。
- **全局（Global）**：所有流量都走代理。排查问题时用，或者某个网站规则判断错了临时切一下。
- **直连（Direct）**：全部不走代理，等于关掉。

那规则模式是**怎么判断**哪些直连、哪些走代理的？答案在订阅自带的「规则集」里。本文只讲选哪个模式，规则集是什么、规则的匹配顺序、能不能自己加一条、以及策略组怎么用，见

## 一定要开自动更新

机场会不断增删节点、更换服务器 IP。**不更新订阅，你就会一直连着已经失效的旧节点**，表现出来就是「昨天还好好的今天全红了」。

在订阅卡片上设置更新间隔，建议 12 或 24 小时。

## 导入失败的五步排查

**一、链接复制不完整。** 中文输入法下容易漏掉结尾字符。重新完整复制一遍再试，这是最常见的原因。

**二、订阅格式不对。** 把通用订阅当 Clash 订阅导，会解析失败。回用户中心确认复制的是 Clash 那一条。

**三、订阅地址本身被墙。** 订阅链接指向机场的服务器，这个域名也可能被墙。**解决办法是先挂着一个已有的可用节点，再更新订阅**——这也是为什么建议在订阅还能用的时候就先存一份配置。

**四、套餐已过期。** 过期后订阅通常返回空列表，客户端表现为「导入成功但没有节点」。

**五、系统时间不准。** 时间偏差超过几分钟会导致部分协议握手失败。看起来像节点问题，实际是本机问题。

如果导入成功但连不上，请转到[机场报错排查](https://jcyyds.com/troubleshoot/)按现象自查。

Clash 对机场几乎没有兼容性限制，绝大多数在营机场都提供 Clash 订阅，所以选择重点不在「支不支持」，而在线路质量和价格档位。
