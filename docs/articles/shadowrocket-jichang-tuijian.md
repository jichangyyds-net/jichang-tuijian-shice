先说清一件事：**Shadowrocket 不提供任何节点**。它是一个 ¥20 出头的付费 App，作用是解析你导入的订阅、按规则分流。节点好不好、晚上卡不卡，跟小火箭没关系，跟你买的机场有关系。

所以「Shadowrocket 机场推荐」这个问题的真实含义是：*在 iOS 上用小火箭，选机场时有哪些额外要考虑的地方*。确实有，而且和 Windows 端不完全一样。

## 买之前先确认 Apple ID 区域

小火箭在中国区 App Store 下架多年，你需要一个**非中国区 Apple ID**（美区最通用）才能买到。这一步卡住的人比想象中多。

几个现实提醒：

- 换区不会丢失现有 App，但换区期间订阅类服务会受影响。
- 用别人的共享账号下载，后续更新时会被要求输入那个账号的密码，长期看很麻烦，也有账号被找回的风险。
- 如果你实在不想折腾 Apple ID，iOS 上还有 Stash、Loon、Quantumult X 等替代品，但它们同样只在非中国区上架，绕不开这一步。其中圈 X 的订阅格式最挑剔，选机场时要额外确认一件事，见[圈 X 机场推荐与订阅格式要求](https://www.jichangyyds.com/topics/quantumult-x/)。

## 小火箭用户选机场，重点看这四项

### 一、协议兼容性

Shadowrocket 的协议支持面很广：Shadowsocks、VMess、VLESS、Trojan、Hysteria2、TUIC 基本都能吃。所以协议本身很少成为瓶颈。

真正需要确认的是**机场是否提供 Shadowrocket 专用的订阅格式**。很多机场的用户中心会针对不同客户端给不同的订阅链接，有的还提供「一键导入」按钮。直接复制 Clash 那条 YAML 订阅塞进小火箭，多数情况下解析不出来。选机场时看一眼它的订阅页面有没有单独列出 Shadowrocket，这是个很小但很实用的筛选条件。具体导入步骤见[订阅导入教程](https://www.jichangyyds.com/guides/)。

### 二、节点数量别贪多

iOS 有内存限制，Shadowrocket 属于 Network Extension，可用内存额度很紧张。**订阅里塞几百个节点，会明显拖慢启动速度，极端情况下直接崩溃。**

所以标榜「500+ 节点」的机场在 iOS 上不是优势，反而是负担。更好的做法是在小火箭里用「配置」功能过滤掉用不上的地区，只保留常用的十几个。选机场时，看它有没有提供**精简版订阅**或按地区分组的订阅，这比节点总数有意义得多。

### 三、移动网络下的稳定性

手机和电脑最大的差别是**网络会不断切换**：Wi-Fi 切 4G、地铁里信号断续、锁屏后连接被系统回收。

这种场景下，基于 UDP 的 Hysteria2 / TUIC 类协议重连速度通常优于 TCP 系协议，体感上「一解锁就能用」。但它们更吃机场服务端的支持，不是所有家都提供。如果你主要在移动中使用，优先看机场节点列表里有没有这类协议节点。

另外，低价走量档在移动网络下的掉线感受会被放大——电脑上卡两秒你可能没察觉，手机上就是刷不出来。这也是为什么手机重度用户建议直接从[稳定机场推荐](https://www.jichangyyds.com/topics/stable/)这一档起步，而不是最便宜那档。

### 四、耗电

代理常驻会增加耗电，这是物理事实，没有客户端能完全避免。但差别在于：**节点质量差、频繁重连的订阅，耗电明显更高**。因为每次断线重连都要重新握手，射频模块反复唤醒。

有人把耗电怪到小火箭头上，实际上换一家线路稳定的机场，续航问题往往就缓解了。

## 小火箭里必须打开的两个设置

**一、订阅自动更新。** 机场会不断增删节点、更换服务器 IP。不自动更新，你就会一直连着已经失效的旧配置，表现出来就是「昨天还好好的今天全红」。

**二、按需连接（On Demand）。** 让小火箭在连上国内 Wi-Fi 时自动断开、连上蜂窝网络时自动启用，能省不少电。

至于全局模式和规则模式，**日常一律用规则模式**。全局模式会把国内流量也绕出去，既慢又白白消耗流量额度。
