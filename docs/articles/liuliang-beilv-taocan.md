买了 100GB 的套餐，用了不到一周就提示流量耗尽。多数情况下不是机场偷你流量，而是你用了高倍率节点却没注意。

## 倍率是什么

**倍率是流量的计费系数。** 节点名字里的 `1x`、`2x`、`0.5x` 就是它。

计算方式很简单：

> **扣除额度 = 实际传输流量 × 倍率**

在 `1x` 节点上下载 1GB，扣 1GB。在 `2x` 节点上下载 1GB，扣 2GB。在 `0.5x` 节点上下载 1GB，只扣 0.5GB。

再补一个很多人忽略的点：**上传和下载都算**。你发出去的请求、上传的文件、视频通话的上行流量，全都计入。日常浏览里上行占比小，但如果你在传大文件或做备份同步，这部分不容忽视。

## 为什么会有倍率

因为不同节点的带宽成本差得很远。

- **专线节点（IPLC / IEPL）** 走运营商内网通道，带宽单价最贵，所以常见 `2x` 甚至更高。
- **跨太平洋线路** 比亚洲近距离线路贵，所以美国、欧洲节点的倍率往往高于港日。
- **冷门地区或高负载已满的节点** 有时会被设成 `0.3x`–`0.5x`，本质是价格杠杆——机场用低倍率把用户从拥挤节点引导过去。

**倍率不是坑，它是成本的诚实反映。** 真正的坑是机场不标注倍率，或者把它藏在文档角落里。节点名里直接写清倍率的机场，通常也更规范。

## 常见倍率区间

| 倍率 | 典型节点 |
| --- | --- |
| 0.2x – 0.5x | 冷门地区、引流用的低优先级节点 |
| 1x | 港台日等常规中转节点，主力 |
| 2x – 3x | 专线节点、部分美国欧洲节点 |
| 5x 以上 | 特殊用途节点，如低并发原生 IP |

线路架构和成本的对应关系见 [IPLC、IEPL 与中转的区别](iplc-iepl-zhongzhuan-zhilian.md)，各地区的定位见[节点地区怎么选](机场节点地区怎么选.md)。

**实操建议**：日常挂着的主力节点务必选 `1x` 或更低，只在真正需要时才切到高倍率节点，用完切回来。很多人「流量莫名其妙没了」，就是因为把 `2x` 的专线节点设成了默认。

## 三种计费模式怎么选

### 一、月付流量套餐（最主流）

买「每月 X GB」，用完等下月重置或加购流量包。

**适合**：用量稳定、每月差不多的人。这是绝大多数人的默认选择，也是最容易横向比价的模式。

**要看清的细节**：流量是**按自然月重置**还是**按购买日重置**？剩余流量能不能结转到下月？（多数不能。）超额之后是断网还是降速？这几条决定了你月底的体验。

### 二、按量计费 / 不限时套餐

买一个固定的流量包（比如 200GB），**不限使用期限**，用完为止。

**适合**：用量波动大、或者用得很少的人。比如你只是偶尔查资料、每月实际用不到 20GB，那么按月付订阅是浪费——你每个月都在为没用掉的额度付钱。

**要看清的细节**：**「不限时」不等于「永久有效」**。很多机场的实际条款是「账号保持活跃状态下有效」，长期不登录可能被回收。买之前一定要翻一下条款，这是这类套餐最常见的纠纷点。

另外，不限时套餐的单价通常高于同等额度的月付套餐——你付的溢价是买时间上的灵活性。

### 三、年付

按年一次性付款，通常有折扣。

**折扣的本质是你借钱给机场并承担风险。** 这个行业的品牌生命周期普遍不长，一旦中途停运，你损失的是整年费用。本站收录的[已跑路机场名单](https://www.jichangyyds.com/scam/)里，不少品牌跑路前都在大力推年付。

**建议**：新品牌一律月付起步，至少完整跑过一个月（含晚高峰）再考虑年付。判断一家机场是否可能跑路的方法见[如何判断机场跑路](ruhe-panduan-jichang-paolu.md)。

## 你到底需要多少 GB

与其看别人推荐，不如自己估。以下是各类行为的大致消耗量级（1x 倍率下）：

| 行为 | 每小时大约 |
| --- | --- |
| 网页浏览、社交、AI 对话 | 几十 MB 到 200MB |
| YouTube 1080P | 1.5–2GB |
| YouTube / Netflix 4K | 6–8GB |
| 音乐流媒体 | 100–150MB |
| 大文件下载 | 等于文件本身大小 |

结论很直接：**只要你不看高清视频，100GB 一个月绰绰有余；只要你天天看 4K，多少 GB 都不够。**

所以选套餐前先问自己一个问题：**我主要是拿它刷网页和用 AI，还是拿它看视频？** 前者选便宜的小流量套餐就行，见[便宜机场推荐](https://www.jichangyyds.com/topics/cheap/)；后者要重点看大流量档和带宽稳定性，见[稳定机场推荐](https://www.jichangyyds.com/topics/stable/)。

## 三个省流量的实用技巧

1. **一定用规则分流，别开全局模式。** 全局模式会把国内流量也绕出去，白白消耗额度，还慢。配置方法见[订阅导入教程](https://www.jichangyyds.com/guides/)。
2. **手机上做分应用代理。** 把国内 App 排除掉，能省下相当可观的一部分。
3. **看视频先降画质。** 从 4K 降到 1080P，流量消耗直接砍到四分之一，而在手机屏幕上你几乎看不出区别。
