# 科学上网是什么：要准备哪三样

> 科学上网就是让访问境外网站的流量走代理。要准备三样：线路（机场订阅）、客户端、分流规则，缺一样都表现成「上不去」。

科学上网指的是让访问境外网站的流量经过代理服务器转发。普通用户要准备三样东西：一份机场订阅，一个客户端，一套分流规则。三样各管一件事，坏了的表现也不同。

## 三样东西各管什么

| 东西 | 管什么 | 坏了的样子 |
| --- | --- | --- |
| 机场订阅 | 提供节点（境外服务器）的列表 | 节点列表是空的，或全部超时 |
| 客户端 | 把你的流量交给节点 | 软件打不开、内核报错、端口被占用 |
| 分流规则 | 决定哪些网站走代理、哪些直连 | 有的网站能开，有的不能 |

很多「科学上网工具」的说法把这三样混在一起讲。分开看，排查时就知道先查哪一层。

## 规则模式与全局模式

客户端一般有三种模式：

- **规则**：国内网站直连，境外网站走代理。日常一直用这个。
- **全局**：所有流量都走代理。只在排查时临时切过去。
- **直连**：所有流量都不走代理，等于关掉。

某个网站打不开时切到全局试一次：全局能开，说明规则把它分到了直连；全局也打不开，问题在节点或订阅。

## 节点协议是什么

节点列表里会看到 Shadowsocks、Trojan、VLESS、Hysteria 2、AnyTLS 等名字，这是节点和客户端之间的通信协议。协议要客户端认得才能用，客户端不认识的节点导进去是灰的。几种新协议的官方说明，整理在主清单的 [协议问答](../../README.md#协议问答anytlsrealityhysteria-2)。

## 先从哪一样开始

先定机场，再按它给的订阅格式挑客户端。反过来做，容易买到只能用自家 App、你的客户端导不进去的机场。具体步骤见 [怎么翻墙：三步从零到能用](怎么翻墙-三步从零到能用.md)。
