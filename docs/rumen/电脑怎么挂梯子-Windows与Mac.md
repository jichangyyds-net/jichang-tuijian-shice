# 电脑怎么挂梯子：Windows 与 Mac

> 电脑挂梯子分两种接管方式：系统代理只管遵守代理设置的软件，TUN（虚拟网卡）接管全部流量。先用系统代理，有软件不走代理再开 TUN。

电脑上挂梯子，就是让客户端接管电脑的网络流量。接管有两种方式：**系统代理**和 **TUN（虚拟网卡）模式**。大多数情况开系统代理就够；某个软件不走代理时，再开 TUN。

## Windows

1. 从 GitHub 官方发布页下载 Clash Verge Rev（Clash 订阅）或 v2rayN（通用订阅）。
2. 解压或安装到英文路径，例如 `D:\ClashVerge\`。路径里有中文或空格，部分版本会出现内核启动失败。
3. 杀毒软件里把整个客户端目录加进排除项。
4. 导入订阅，选节点，打开系统代理。

## macOS

1. 下载与芯片对应的安装包（Apple 芯片选 arm64 / aarch64，Intel 芯片选 x64），以发布页的文件说明为准。
2. 首次打开若提示无法验证开发者，到「系统设置 → 隐私与安全性」里允许打开。
3. 导入订阅，选节点，打开系统代理。

## 系统代理和 TUN 的区别

| | 系统代理 | TUN（虚拟网卡）模式 |
| --- | --- | --- |
| 接管范围 | 遵守系统代理设置的软件（浏览器等） | 电脑的全部流量 |
| 需要的权限 | 普通权限 | Clash Verge Rev 要求安装服务模式或以管理员身份运行 |
| 什么时候用 | 日常默认 | 命令行工具、游戏、某些桌面软件不走系统代理时 |

Clash Verge Rev 对 TUN 的说明原文：「TUN（虚拟网卡）模式接管系统所有流量，启用时无须打开系统代理」；没装服务时会提示「TUN 模式需要安装服务模式或管理员模式」（取自其源码语言包，2026-10-13 读取）。

## 挂上了但某个软件还是连不上

1. 先看浏览器能不能打开境外网站。浏览器能、那个软件不能，就是它不走系统代理。
2. 在那个软件的设置里单独填代理地址（客户端设置页里能看到本地端口），或者改开 TUN。
3. 开 TUN 后记得关掉系统代理，避免两层叠在一起。

## 两个客户端不要同时开

两个代理客户端会抢同一个本地端口，后启动的那个必然报错。换客户端前先完全退出旧的。
