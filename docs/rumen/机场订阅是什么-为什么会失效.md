# 机场订阅是什么、为什么会失效

> 机场订阅是一条返回节点列表的链接。失效有四种：类型拿错、套餐到期或被重置、订阅地址访问不到、外传触发风控。四种的修法各不相同。

机场订阅（节点订阅）是机场给你的一条链接，客户端访问它，拿回当前可用的节点列表。订阅「失效」有四种原因，表现相似，修法完全不同。

## 订阅的几种类型

同一家机场常给好几种订阅链接，名称大致是：

| 名称 | 给谁用 |
| --- | --- |
| Clash 订阅 | Clash Verge Rev、FlClash 等 Clash 系客户端 |
| 通用订阅 / V2Ray 订阅 / Base64 订阅 | v2rayN、v2rayNG、Shadowrocket |
| sing-box 订阅 | sing-box 系客户端 |

## 四种失效，怎么分

**1. 类型拿错。** 导入后节点列表是空的，或者报格式错误。把 Clash 订阅导进 v2rayN 就是这样。修法：回后台复制对应类型。

**2. 套餐到期或订阅被重置。** 原来能用，突然全部失效。套餐到期、你在后台点了「重置订阅」，旧链接都会作废。修法：到后台看到期日，重新复制链接。

**3. 订阅地址访问不到。** 更新订阅时报错、超时。很多机场的订阅地址本身在境外，没有可用代理时拉不下来；机场更换订阅域名时也会这样。修法：先用浏览器直接打开订阅链接看能不能返回内容；打不开就去看机场公告。

**4. 外传触发风控。** 把订阅发给别人，多台陌生设备同时用，机场会限速或封号，症状像被墙。修法：联系机场，重置订阅，以后别外传。

## 第一次导入的时机

第一次导入订阅，要在网络能通的时候做。换电脑、重装系统后订阅全部失效，多数是第 3 种：新环境里没有代理，订阅地址拉不下来。

## 订阅要多久更新一次

机场会加线路、换 IP、下线故障节点。客户端一般能设自动更新间隔；节点大面积超时时，先手动更新一次订阅再排查别的。
