# Clash 节点从哪来、怎么看好坏

> Clash 节点来自机场订阅，订阅更新时客户端拉取节点列表。看好坏用三件事：同一时段的延迟分布、晚高峰实际可用、流量倍率。本页不涉及任何免费节点来源。

Clash 里的节点（代理节点）来自你导入的机场订阅：客户端每次更新订阅，就从机场服务器拉回一份节点列表。节点好不好，不看单次延迟数字，看三件事：同一时段多次测的分布，晚高峰能不能正常用，倍率是多少。

## 节点、订阅、机场的关系

- **机场**：运营服务器的服务商，你向它买套餐。
- **订阅**：一条链接，里面是机场当前可用节点的列表。
- **节点**：列表里的每一项，对应一台境外服务器和一种协议。

节点会变：机场会加线路、换 IP、下线故障节点。所以订阅要定期更新，不是导一次就永远有效。

## Clash 里的延迟数字是怎么来的

点「测延迟」时，客户端通过这条节点向一个固定测试网址发一次请求，记录拿到响应的耗时。它只测一次往返，不测带宽。所以：

- 显示 80ms 但视频一直缓冲：延迟测试本来就不测带宽。
- 同一节点两次差很多：单次采样，波动正常。
- 换个客户端数字对不上：默认测试网址不同，跨客户端比没有意义。

## 判断节点好坏的步骤

1. **同一时段测三次。** 晚上九点左右，连续三天，测同一条节点。
2. **看最差的一次。** 三天里最差那次还能正常看 1080p，这条节点就能用。
3. **看倍率。** 节点名或机场说明里标了 1.5x、2x 的，用 1GB 扣 1.5GB、2GB 套餐流量。倍率怎么折算见 [流量倍率与套餐怎么算](../articles/liuliang-beilv-taocan.md)。
4. **看实际要用的网站。** 延迟测试通过，不代表这条线路对你要用的网站是通的。

## 为什么不写免费节点

网上流传的免费节点多是公开分享的临时节点：存活时间短，来源不可控，你的全部流量要经过陌生人的服务器。本仓库不收录、不链接任何免费节点来源。
