# 梯子软件哪个好用：按设备选客户端

> 梯子软件只是客户端，本身不带节点。按设备和机场给的订阅格式选：Clash 订阅配 Clash 系，通用订阅配 v2rayN / v2rayNG。

梯子软件本身不带任何节点，它是读取机场订阅、把流量转给节点的客户端。哪个好用取决于两件事：你用什么设备，你的机场给什么格式的订阅。两件事对上了，软件之间差别不大。

## 第一步：看你的机场给什么订阅

| 机场后台给的链接 | 能直接用的客户端 |
| --- | --- |
| Clash 订阅 | Clash Verge Rev、FlClash、mihomo 内核类客户端 |
| 通用订阅 / V2Ray 订阅 / Base64 订阅 | v2rayN、v2rayNG、Shadowrocket |
| 不给订阅链接 | 只能用机场自己的 App |

本仓库收录的品牌各自属于哪一类，见主清单 [客户端推荐](../../README.md#客户端推荐) 里的订阅方式统计表。

## 第二步：按设备挑

| 设备 | Clash 订阅用 | 通用订阅用 | 下载 |
| --- | --- | --- | --- |
| Windows | Clash Verge Rev | v2rayN | GitHub 官方发布页 |
| macOS | Clash Verge Rev | v2rayN | GitHub 官方发布页 |
| 安卓 | FlClash | v2rayNG | GitHub 官方发布页 |
| iPhone / iPad | 有的机场单独给「Shadowrocket 订阅」，以后台为准 | Shadowrocket | App Store（中国大陆区搜不到） |

官方发布页地址见 [客户端推荐](../../README.md#客户端推荐)。

## 第三步：装好后验证

1. 导入订阅，节点列表出现。
2. 选一个节点，打开系统代理。
3. 打开一个境外网站，再打开一个国内网站。两个都正常，规则模式就配对了。

## 下载时的三条规矩

- **只从官方发布页下载。** 第三方下载站的安装包可能被二次打包，代理软件被动了手脚，等于把全部流量交给陌生人。
- **「梯子下载」搜到的打包版本不要装。** 官方项目都在 GitHub 发布，不需要第三方转存。
- **杀毒软件会删代理内核。** 把整个客户端目录加进白名单，只加单个 exe 不够。
