# 翻墙加速器和机场的区别

> 「加速器」一词指三种东西：游戏加速器、成品翻墙 App、机场。三者用途不同，买错最常见的是拿游戏加速器去看境外网站。

「翻墙加速器」「梯子加速器」「加速器梯子」这几个词搜的人不少，但「加速器」这个叫法底下其实是三种不同的东西。先分清是哪一种，再决定买什么。

## 三种「加速器」

| 类型 | 主要用途 | 能不能打开境外网站 |
| --- | --- | --- |
| 游戏加速器 | 优化特定游戏到游戏服务器的连接 | 一般只加速它支持的游戏，不是通用的访问工具 |
| 成品翻墙 App（自称加速器） | 通用访问境外网站 | 能，属于成品 VPN 一类 |
| 机场 | 提供节点订阅，配合客户端使用 | 能，需要自己配客户端 |

## 怎么判断你搜到的是哪一种

1. **看它说加速什么。** 页面列的是一串游戏名，就是游戏加速器。
2. **看它给不给订阅链接。** 给订阅链接、让你装 Clash / v2rayN 的，是机场。
3. **看它是不是只有自家 App。** 只有自家 App、登录就连的，是成品翻墙 App。

## 用机场能不能加速游戏

能接管游戏流量，但要满足两个条件：客户端开 TUN（虚拟网卡）模式，因为很多游戏不走系统代理；节点要选离游戏服务器近、延迟低的地区。机场的线路是为通用访问设计的，打游戏的效果因线路而异。本仓库按「游戏低延迟」筛过一份名单，见 [游戏低延迟机场推荐](../scenarios/gaming.md)。

## 买错了怎么办

先买月付或最短周期。用一周还不确定，就别续。三种东西的退款规则各不相同，以各家条款为准。
