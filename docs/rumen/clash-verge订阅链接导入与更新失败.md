# Clash Verge 订阅链接导入与更新失败

> Clash Verge Rev 导入订阅只要三步：「订阅」页粘贴链接、点「导入」、选中后启用。本页按它界面上的报错原文逐条给出原因和处理办法。

在 Clash Verge Rev 里导入机场订阅：打开「订阅」页，把链接粘进输入框，点「导入」，再点选这份订阅使它生效。下文的界面文字取自 Clash Verge Rev 源码里的中文语言包（`src/locales/zh/`，2026-10-13 读取）；你装的版本若措辞不同，以应用内显示为准。

## 导入步骤

1. 在机场后台复制 **Clash 订阅** 链接。
2. 打开 Clash Verge Rev，左侧点「订 阅」。
3. 在输入框（提示文字「订阅文件链接」）里粘贴，点「导入」。
4. 订阅卡片出现后点选它，使它成为当前订阅。
5. 到「代 理」页选节点，回首页打开「系统代理」。

## 报错原文与处理

| 界面提示 | 原因 | 处理 |
| --- | --- | --- |
| 无效的订阅链接，请输入以 http:// 或 https:// 开头的地址 | 复制时漏了开头，或粘进了别的内容 | 回后台重新复制完整链接 |
| 订阅导入失败，尝试使用 Clash 代理导入 | 直接访问订阅地址失败，客户端改用已有代理重试 | 等它重试；若随后提示「使用 Clash 代理导入订阅失败」，看下一行 |
| 使用 Clash 代理导入订阅失败 | 订阅地址打不开，且当前没有可用代理 | 浏览器直接打开订阅链接，看能否返回内容；确认套餐未到期 |
| 订阅已导入，但可能需要手动刷新 | 导入成功，列表没刷新 | 点「更新所有订阅」或重启应用 |
| 更新订阅失败 | 订阅过期、被重置，或订阅域名更换 | 到机场后台看到期日，重新复制链接 |

## 导入成功但上不了网

- **没开系统代理。** 首页提示「系统代理已关闭，建议大多数用户打开此选项」时，流量没经过客户端。
- **某个软件不走系统代理。** 改用「虚拟网卡模式」（TUN）。它要求安装服务模式或以管理员身份运行，否则会提示「TUN 模式需要安装服务模式或管理员模式」。
- **全部节点超时。** 先看套餐和流量，再看 [节点全部超时怎么办](../articles/jiedian-quanbu-timeout.md)。
