# 怎么翻墙：三步从零到能用

> 怎么翻墙的操作步骤：选一个有订阅链接的机场、装对客户端、导入订阅并打开系统代理，附每一步最常见的卡点。

翻墙要做的事只有三步：买一份带订阅链接的机场套餐，装一个能读这种订阅的客户端，把订阅导进去再打开系统代理。下面按顺序写，每一步后面列出最常卡住的地方。

## 第一步：买一份带订阅链接的套餐

先确认这家机场给不给订阅链接。本仓库收录的品牌里，有一批暂不提供订阅链接，只能用它自己的 App；买之前看主清单的 [按订阅方式筛选](../../README.md#按订阅方式流量重置筛选30-家) 那张表。

第一次买，选月付最低档。目的是验证，不是省钱。

**卡点**：付完款找不到订阅链接。它通常在机场后台的「仪表盘」或「使用文档」里，名称多是「复制订阅」之类，每家叫法不同，以后台显示为准。

## 第二步：装客户端

按设备装，只从官方发布页下载：

| 设备 | 客户端 |
| --- | --- |
| Windows / macOS | Clash Verge Rev 或 v2rayN |
| 安卓 | FlClash 或 v2rayNG |
| iPhone / iPad | Shadowrocket（非中国大陆区 App Store） |

官方地址集中在主清单的 [客户端推荐](../../README.md#客户端推荐)。

**卡点**：v2rayN 和 v2rayNG 是两个软件，一个电脑版、一个安卓版，教程不能混用。

## 第三步：导入订阅，打开系统代理

1. 回机场后台，复制和你的客户端对应的那种订阅：用 Clash 系就复制 Clash 订阅，用 v2rayN / v2rayNG 就复制通用订阅。
2. 在客户端里新建订阅，粘贴链接，保存后更新。节点列表出现，导入就成功了。
3. 选一个节点，打开系统代理。

**卡点**：只选了节点、没开系统代理，浏览器的流量根本没经过客户端。Clash Verge Rev 首页的提示原文是「系统代理已关闭，建议大多数用户打开此选项」（取自其源码语言包，2026-10-13 读取）。

## 做完三步还是打不开

按这个顺序查，每一步只排除一种原因：

1. 关掉客户端，本地能不能正常上网。不能，问题在你的网络。
2. 套餐有没有到期、流量有没有用完。去机场后台看。
3. 订阅能不能更新。更新报错是订阅层的问题；更新成功但节点全部超时，是线路层的问题。
4. 换到全局模式试一次。全局能开、规则模式打不开，是分流规则把那个网站分到了直连。

更细的排查见 [节点全部超时怎么办](../articles/jiedian-quanbu-timeout.md)。
