# 术语表

选机场时会反复遇到的词。按理解难度排序，不是按字母。

## 线路类型

**直连**
你的流量从家宽直接连到境外服务器，中间不经过任何中转。
成本最低，晚高峰最容易掉速——因为国际出口在晚上是拥堵的。

**中转**
先连到一台境内或近岸的中转服务器，再由它转发到境外落地。
中转商可以选质量更好的出口，所以晚高峰通常比直连稳。
多数「主流性价比」档位的机场用的是这个。

**BGP 中转**
中转服务器接了多条运营商线路，能按实时质量自动选路。
比单线中转稳，成本也更高。

**CN2**
中国电信的一条优质国际线路（分 GT 和 GIA 两个等级，GIA 更好）。
它是「更好的公网」，**不是专线**——晚高峰依然会受公网拥堵影响，只是轻一些。

**IPLC（国际私线电路）**
运营商拉的一条**物理专线**，两端点对点，流量不经过公网国际出口。
所以它**不受晚高峰拥堵影响**，延迟极稳定。代价是贵——
这就是「高价专线档」价格高出一截的原因。

**IEPL**
和 IPLC 同类，区别在底层实现（IEPL 走以太网，IPLC 走 SDH/MPLS）。
对用户来说体验接近，都属于专线。

> 详解见 [IPLC、IEPL、中转、直连有什么区别](articles/iplc-iepl-zhongzhuan-zhilian.md)

## 计费相关

**流量倍率**
同样传 1GB，不同节点扣的流量不一样。
专线节点常见 2x–5x 倍率，意思是传 1GB 扣 2–5GB 套餐流量。
**看套餐标的「500GB」时一定要看倍率**，否则实际可用量差好几倍。

**每 GB 成本**
`套餐价 ÷ 套餐流量`。横向比较性价比唯一不受包装影响的口径。

**不限时流量包**
一次性买断的流量，不按月清零。适合用量不稳定的人。

## 节点与 IP

**落地 IP**
你的流量最终从哪个 IP 出去。流媒体和 AI 服务看的是这个。

**原生 IP**
该 IP 归属地与服务器所在国家一致，且注册为住宅或普通商用。
**ChatGPT、Claude 这类 AI 服务对这个很敏感**——机房 IP 经常直接被拦。

**机房 IP**
数据中心的 IP。速度通常更快，但被流媒体和 AI 风控识别的概率高得多。

**超售**
机场卖出的总带宽超过实际拥有的带宽。
行业普遍存在，**关键是超售比例**——比例过高就是晚高峰卡顿的直接原因。

## 时段

**晚高峰**
工作日 20:00–23:00。国际出口最拥堵的时段。
**只有这个时段的测速数据才有参考价值**，白天测什么都好看。
