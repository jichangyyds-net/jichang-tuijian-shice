# sing-box 机场推荐

> sing-box 机场推荐 2026｜支持 Hysteria2 / TUIC 的机场。数据快照 2026-08-23。


sing-box 与 Hiddify 用户如何选择机场？本页说明 Hysteria2、TUIC、VLESS Reality 等新协议的兼容要求、流量倍率差异，以及为什么不该用来路不明的第三方订阅转换服务。

**筛选标准**

- **确认机场是否真的提供新协议节点** 很多机场只在宣传页提到 Hysteria2，实际订阅里仍是 Shadowsocks。下单前可以直接问客服要一条示例节点确认。
- **新协议更吃流量倍率** Hysteria2 这类基于 UDP 的协议会有额外开销，部分机场会对其单独设置更高的流量倍率，注意套餐说明。
- **需要机场提供 sing-box 订阅** 否则要靠第三方订阅转换服务，等于把你的订阅内容交给一个陌生的中间人，有隐私风险。
