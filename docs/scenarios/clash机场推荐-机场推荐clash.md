Clash / Clash Verge / Clash Meta（Mihomo）用户怎么选机场？本页说明各家的订阅格式要求、为什么优先选提供 Clash 专属订阅的机场、节点命名带不带地区与倍率对分流的影响，以及规则分流与策略组的常见坑。附支持 Clash 订阅的在营机场与优惠码。

**筛选标准**

- **优先选提供 Clash 专属订阅的** 通用订阅需要靠客户端自行转换，容易丢失分组和规则。原生提供 Clash 配置的机场，导入后策略组、地区分组、流媒体分流是现成的。
- **看节点命名是否带地区和倍率** 规范的机场会在节点名里标明地区、线路类型和流量倍率（如 1x / 2x）。命名混乱的机场，你很难判断自己在用哪条线、扣多少流量。
- **确认支持 Clash Meta 内核** Hysteria2、TUIC、VLESS Reality 等新协议需要 Meta（Mihomo）内核。如果机场主推这些协议，要确认你的客户端版本跟得上。
