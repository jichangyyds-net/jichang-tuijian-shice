# 梯子和机场是一回事吗

> 「梯子」是翻墙工具的统称，「机场」是其中一种：卖订阅、你用自己的客户端连。VPN 应用、自建服务器、机场订阅都可以被叫作梯子，但三者的付费方式、可控程度和风险完全不同。

**一句话回答：** 机场是梯子的一种。说「买梯子」时，多数人实际买的是机场订阅；但一些打着「梯子」「加速器」旗号的一体化 App，和机场不是同一类东西。

## 常说的三种「梯子」

| | 机场订阅 | 一体化 VPN / 加速器 App | 自建服务器 |
| --- | --- | --- | --- |
| 你买的是什么 | 一条订阅链接（多个节点） | 一个自带线路的 App | 一台海外服务器 |
| 用什么客户端 | 提供订阅链接的，可以自己选 Clash 系、Shadowrocket、v2rayN 等；不提供的只能用官方客户端 | 只能用它自己的 App | 自己装、自己配 |
| 节点数量 | 多地区多节点，可切换 | 由 App 决定 | 通常只有这一台 |
| 分流 | 规则分流，国内直连 | 取决于 App | 自己写规则 |
| 价格形态 | 按月 / 按流量 | 按月会员 | 服务器月租 + 流量 |
| 技术门槛 | 低：粘贴订阅链接 | 最低 | 高 |
| 主要风险 | 服务商跑路、订阅泄露 | App 来源不明、收集数据 | IP 被封、维护成本 |

## 为什么很多人把机场叫梯子

「梯子」是比喻：借一个东西翻过墙。早期大家用的是各种代理工具，后来机场订阅成了最普遍的形态，两个词就混着用了。搜「梯子推荐」「机场梯子」的人，大多数想找的是可靠的机场订阅。

## 怎么判断你搜到的是哪一种

| 看到的描述 | 通常是 |
| --- | --- |
| 「订阅链接」「支持 Clash / Shadowrocket」「节点」「流量 GB」 | 机场 |
| 「一键连接」「下载 App 即可」「会员」，不提订阅 | 一体化 App |
| 「VPS」「搭建教程」「服务器」 | 自建 |

## 一体化 App 要多看一眼

- 应用商店里名字带「梯子」「加速器」「VPN」的应用很多，开发者各不相同，先看开发者是谁。
- 只能用它自己的 App，意味着流量怎么走、记录什么，你无法用第三方工具核对。
- 机场也不都能配第三方客户端。按各服务商官方公告（2026-08-09 核对），本站实测的 16 家里有 11 家暂不提供订阅链接、只能用官方客户端，见 [机场推荐 2026：晚高峰实测数据](机场推荐2026-晚高峰实测数据.md) 的「订阅方式」一列。

## 选机场时看什么

- 晚高峰表现：工作日 20:30–22:30 实测。
- 客户端兼容：是否提供订阅链接。想用 Clash、Shadowrocket 的，这一项要最先确认。
- 条款透明：流量计算、倍率、设备数、退款。
