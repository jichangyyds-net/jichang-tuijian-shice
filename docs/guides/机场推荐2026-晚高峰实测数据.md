## 测试口径（读数字之前必须看）

- **时间**：2026-07-19 至 2026-07-21，工作日晚高峰，每家的具体时间见表内「实测时间」（北京时间）。
- **中位数**：每个地区取该地区所有可用节点下载速度的中位数，不是最快节点。失败或速率极低的节点不计入中位数，但体现在「可用 / 总节点」里。
- **不可横向比较**：各家测试入口的带宽不同（1Gbps / 2Gbps / 10Gbps）、并发线程数不同，客户端本身的带宽上限就不一样。**A 家香港 120 与 B 家香港 90，不能得出 A 比 B 快的结论。**
- **解锁判定**：按全部节点中可解锁的占比，≥80% 记 ✓，≥30% 记「部分」，否则 ✗；单个节点可能不同。
- **时效**：数据距本页生成约两个月，服务商线路可能已调整。

## 怎么用这张表

1. 先按用途筛：要用 ChatGPT / Gemini 的，看前两列是否为 ✓。
2. 再按客户端筛：习惯 Clash、Shadowrocket 的，只看「提供订阅链接」的几家；其余只能用服务商自己的客户端。
3. 看你常用地区的节点在该家内部是不是明显偏慢（同一行里横向比）。
4. 第一次买只买月付，在自己网络的晚高峰再测一次。
