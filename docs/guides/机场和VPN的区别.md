# 机场和 VPN 的区别

> 机场是面向个人的代理订阅服务，按规则分流，只让需要的流量出境；传统 VPN 是把整台设备的流量接入另一个网络。两者都能访问海外网络，但工作方式、协议、客户端和适用场景不同。

**一句话回答：** 机场卖的是多节点代理订阅，配合 Clash 这类客户端按规则分流；传统 VPN 是整机隧道，设计初衷是接入远程网络。日常访问海外网站，多数人用的是机场。

## 核心区别

| | 机场 | 传统 VPN |
| --- | --- | --- |
| 本质 | 代理服务，提供多个节点的订阅 | 虚拟专用网络，建立加密隧道 |
| 流量怎么走 | 规则分流：国内直连、海外走代理 | 通常整机流量都进隧道 |
| 常见协议 | Shadowsocks、VMess、VLESS、Trojan、Hysteria2 等 | OpenVPN、WireGuard、IPsec、L2TP 等 |
| 客户端 | 提供订阅链接时可用 Clash 系、Shadowrocket、v2rayN、sing-box；否则用服务商自己的客户端 | 通常用服务商自己的 App 或系统内置 VPN |
| 节点 | 多地区、可随时切换 | 选一个服务器连接 |
| 计费 | 按月 / 按流量 GB | 多为按月会员 |
| 设计初衷 | 访问海外网络 | 企业远程办公、接入内网 |

## 「机场」这个名字从哪来

代理节点常被叫作「飞机」，提供大量节点的服务商就被叫作「机场」，订阅像是航班表。这是中文圈约定俗成的叫法，和航空机场没有关系。

## 为什么日常多用机场

1. **分流更省心**：国内网站不绕路，速度和流量都不浪费。
2. **节点多**：一个地区不稳可以换另一个。
3. **客户端可以自己选**：前提是服务商提供订阅链接。按各服务商官方公告（2026-08-09 核对），本站实测的 16 家里只有 5 家提供订阅链接（且部分第三方客户端不支持），其余只能用官方客户端，买前先确认。

## 什么情况更适合 VPN

- 公司要求用指定 VPN 接入内网。
- 只需要一台设备整机走某个固定出口。

## 手机上显示的「VPN」图标是怎么回事

在手机上使用机场订阅时，Clash Meta for Android、Shadowrocket 这类客户端会调用系统的 VPN 接口来接管流量，所以状态栏会出现 VPN 图标。这是系统提供的接管方式，不代表你用的是传统 VPN 服务。

## 选机场的判断标准

- 晚高峰实测，而不是宣传截图。
- 条款透明：流量、倍率、设备数、退款写清楚。
- 有备用订阅地址和公告渠道。
